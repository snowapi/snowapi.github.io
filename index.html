МАС «Снежинка» API Christofari Neo / Росатом

Base URLhttps://christofari-neo.snowapi.ru/
AuthBearer <API-ключ VK Play>
Бесплатный тариф100 запр/день + 10 квантовых задач
ФорматJSON
Асинхронные задачиjob_id + статус
ИнфраструктураChristofari Neo + Росатом
Единый вычислительный шлюз – Christofari Neo. Все запросы первично направляются на суперкомпьютер Christofari Neo (Сбер), который выполняет маршрутизацию, классическую предобработку и оркестрацию. Квантовые задачи автоматически перенаправляются в инфраструктуру Госкорпорации «Росатом» (ионные ловушки, квантовый отжиг, нейтральные атомы). Пользователь взаимодействует только с единым эндпоинтом, не задумываясь о внутреннем распределении.
Аутентификация: все запросы должны содержать заголовок Authorization: Bearer <ваш_ключ>. Ключ выдаётся в личном кабинете VK Play после подтверждения партнёрства с Росатомом.

1. Биоинформатика

POST/bio/analyze
Анализ биологических последовательностей (ДНК/РНК/белок). Выполняется на классических узлах Christofari Neo.
{
  "sequence": "ATCGATCG...",
  "type": "dna | rna | protein",
  "tasks": ["gc_content", "molecular_weight", "secondary_structure"]
}

{
  "gc_content": 0.45,
  "molecular_weight": 12345.6,
  "secondary_structure": "hairpin"
}

5. Фолдинг белков и ДНК

POST/folding/predict
Предсказание 3D-структуры. При указании квантового провайдера задача направляется на соответствующий QPU Росатома через шлюз Christofari Neo.
{
  "sequence": "MVLSPADKTNVKAAW...",
  "molecule_type": "protein",
  "engine": "auto | deepfold-plm | quantum_annealing | quantum_gate",
  "quantum_provider": "rosatom_annealer | rosatom_ion | rosatom_neutral",
  "options": {
    "return_pdb": true,
    "num_reads": 1000
  }
}

{
  "job_id": "fold_550e8400",
  "status": "pending"
}
GET/folding/result/{job_id}

6. Квантовые вычисления (Росатом)

Доступны российские квантовые процессоры, разработанные в рамках дорожной карты «Квантовые вычисления». Доступ к ним осуществляется через шлюз Christofari Neo – запросы автоматически перенаправляются в Национальную квантовую лабораторию (Росатом).

Доступные технологии через провайдера rosatom_*

Провайдер (значение)ТипТехнологияПрименение
rosatom_annealerКвантовый аннилерРоссийский аналог D‑Wave (отжиг)Оптимизация QUBO, отбор молекул
rosatom_ionВентильный (ионная ловушка)50+ физических кубитов, точность 99.7%Точный докинг (QAOA), квантовая химия
rosatom_neutralВентильный (нейтральные атомы)Массивы атомов (опытные образцы)Материаловедение, симуляция решёток
rosatom_simСимуляторКлассический эмулятор на CPU/GPUОтладка и тестирование (бесплатно)
POST/quantum/optimize
Многокритериальная оптимизация (QUBO) на квантовом аннилере Росатома.
{
  "provider": "rosatom_annealer",
  "problem_type": "qubo",
  "qubo": {
    "linear": {"0": -1, "1": -2},
    "quadratic": {"0,1": 3}
  },
  "params": {
    "num_reads": 1000,
    "annealing_time": 20
  }
}

{
  "job_id": "qopt_550e8400",
  "status": "pending"
}
POST/quantum/docking
Молекулярный докинг с использованием гибридного алгоритма QAOA на ионной ловушке.
{
  "provider": "rosatom_ion",
  "molecule_smiles": "CCO",
  "target_pdb": "3ERT",
  "options": {
    "hybrid_jobs": true,
    "classical_instances": "ml.m5.xlarge"
  }
}
POST/quantum/chemistry
Симуляция электронной структуры (VQE) на вентильном процессоре.
{
  "provider": "rosatom_ion",
  "system": "ferrocene",
  "method": "vqe",
  "basis_set": "sto-3g"
}

Стоимость и лимиты

Бесплатный тариф (ознакомительный):

  • 100 классических запросов в день (био, хемо, L‑системы, анимации).
  • 10 квантовых задач в сутки (суммарно на всех провайдерах).
  • Неограниченное использование симулятора rosatom_sim.

Коммерческое использование: цены рассчитываются индивидуально в зависимости от типа QPU, длительности сессии и количества запусков. Для получения коммерческого предложения обратитесь к менеджерам Госкорпорации «Росатом» через личный кабинет VK Play.

Все квантовые задачи выполняются на реальном российском оборудовании, развёрнутом в Национальной квантовой лаборатории (Росатом).

Примеры cURL

# Получить шаблоны анимаций
curl -H "Authorization: Bearer YOUR_API_KEY" \
     https://christofari-neo.snowapi.ru/animations/templates

# Запустить фолдинг с квантовым отжигом (российский аннилер)
curl -X POST -H "Authorization: Bearer YOUR_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{
         "sequence": "MVLSPADKTNVKAAW...",
         "molecule_type": "protein",
         "engine": "quantum_annealing",
         "quantum_provider": "rosatom_annealer"
     }' \
     https://christofari-neo.snowapi.ru/folding/predict

# Оптимизация QUBO на аннилере
curl -X POST -H "Authorization: Bearer YOUR_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{
         "provider": "rosatom_annealer",
         "problem_type": "qubo",
         "qubo": {"linear":{"0":-1,"1":-2},"quadratic":{"0,1":3}},
         "params": {"num_reads": 1000}
     }' \
     https://christofari-neo.snowapi.ru/quantum/optimize
